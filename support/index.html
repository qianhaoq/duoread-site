DuoRead 支持

DuoRead 是本地 Markdown / PDF 阅读与笔记应用：空间充足时左侧阅读、右侧记笔记；无账号、无网络请求。Markdown 为轻量子集渲染（标题、粗体、斜体、无序列表、行内 code），不是完整 CommonMark。

常见问题

如何导入文档？
在 App 内通过系统「文件」选择器导入 .md、.markdown、.pdf 或 .txt。应用会将副本保存在本地应用空间，不会改动你选择的原文件。
笔记保存在哪里？
笔记与文本 / PDF 阅读进度保存在应用本地存储。无云同步；主动导出的笔记会保存到你在系统导出器中选择的位置。
是否收集数据？会联网吗？
不收集任何数据。无账号、无分析、无广告、无第三方 SDK；App 不发起任何网络请求。详见 隐私政策。
如何删除数据？
可在文档列表中删除导入的文档及其关联笔记和阅读进度（不影响原文件）。删除 App 可移除其本地保存的数据；系统备份与你主动导出的副本需另行管理。
系统要求是什么？
需要 iOS 27.1 或更高版本。双栏阅读与笔记布局取决于可用空间和 size class；空间不足时以单栏只读查看当前文档。
如何付费？有没有订阅？
一次买断（各地区价格以 App Store 显示为准，规划约 $4.99 / ¥28），无订阅、无应用内续费。

隐私政策 / Privacy Policy

Support (English)

DuoRead is a local Markdown / PDF reader with notes: read on the left and take notes on the right when space allows. No account, no network requests. Markdown uses a lightweight subset (headings, bold, italic, unordered lists, inline code)—not full CommonMark.

  • Import: Use the system Files picker for .md, .markdown, .pdf, or .txt. A copy is stored in local app storage.
  • Where notes live: Local app storage only. No cloud sync. Explicit exports go where you choose in the system exporter.
  • Data / network: Does not collect any data; the app does not initiate any network requests. See the Privacy Policy.
  • Delete data: Remove documents (and related notes/progress) in the list, or delete the app. Backups and exports are managed separately.
  • Requirements: iOS 27.1 or later. Two-pane layout depends on available space.
  • Pricing: One-time purchase (about $4.99 / ¥28; store price prevails). No subscriptions.
